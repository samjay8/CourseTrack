# COS 201 Programming I — Mid-Semester Lab Assessment

Transcribed from the official MIVA Open University brief so every requirement can be traced to code.

## Case study: Student Course Management (Mini-System)

Design and implement a simple Student Course Management System that helps students record and manage the courses they take in a semester: add courses, display all recorded courses, search for specific courses, compute total credit units, and save or load the course list from a file. A text-based menu or a simple graphical interface may be used.

## 1. Core functionality
- Add new courses with details such as course code, course title, and unit.
- Store all courses in a manageable internal structure.
- Display all stored courses clearly.
- Search for a course using its code.
- Calculate and display the total number of units entered.
- Save recorded courses to a file.
- Load previously saved courses from a file.

## 2. Program design
- Proper use of classes and objects.
- Methods for performing various operations.
- Logical decision-making for menu selection.
- Effective handling of invalid input.
- Simple string processing (e.g. trimming, casing, validation).
- Clean and structured coding style.

## 3. Additional technical features
- Use of iteration (loops).
- Use of a simple recursive feature (e.g. a recurring menu display or a recursive search/count function).
- Appropriate error handling through exceptions.
- File reading and writing for saving/loading the course list.
- A simple GUI or an organized console-based interface.

## 4. Expected operations (minimum)
1. Add Course
2. View All Courses
3. Search Course by Code
4. Compute Total Units
5. Save to File
6. Load from File
7. Exit Program

## Submission
- All source code files.
- A screenshot showing the program running.
- A short report (1–2 pages) summarizing: what the system does, how each major feature works, challenges encountered (how errors were handled), and where recursion was applied.
